### Code / scripts

- **`scripts/cuda-bringup.sh`** (new, 130 lines, exec bit set,
  `bash -n` clean). Idempotent first-run validation for the RTX
  6000 host. What it does:
  1. Sanity-checks the host (must be Linux; `nvidia-smi` must be on
     PATH; `nvcc` is a soft dep — risc0 ships its own CUDA via
     `cust`, so we only warn).
  2. Snapshots host info to `target/cuda-bringup/host-info.txt`
     (uname, nvidia-smi, nvcc, rustc, cargo).
  3. Builds `seal-zk` with `risc0 local-prover risc0-zkvm/cuda
     gpu-cuda` (release, `--tests`).
  4. Runs `test_risc0_full_pipeline` under `/usr/bin/time -v` to
     capture wall-time + peak RSS. Falls back to the bash builtin
     if GNU time isn't installed (peak RSS goes NA in that case).
     Forces `RISC0_DEV_MODE=0` so the CUDA segment prover actually
     fires (dev-mode emits a 361-byte receipt in 0.02 s and skips
     the segment prover entirely).
  5. Parses the elapsed time + peak RSS + receipt size and writes
     them to `target/cuda-bringup/results.txt` plus appends to
     `results.csv` (`timestamp_unix,wall_seconds,peak_rss_kb,
     receipt_bytes,gpu_name`). The CSV is append-only so re-runs
     build a history.
  6. Prints the CPU baseline alongside (10.9 s wall / 657 MB peak
     RSS / 205 842-byte receipt, M-series, 2026-04-19) so the
     speedup is visible at a glance.
  Pins `CUDA_VISIBLE_DEVICES=0` and `RUST_MIN_STACK=16MB` per the
  local-prover guidance in `crates/seal-zk/Cargo.toml`.
