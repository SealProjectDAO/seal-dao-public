  ---                                                                                                                                                  
  Interactive Demo                                                                                                                                     

  cargo run -p seal-cli -- demo

  Shows end-to-end in one shot:                                                                                                                        
  - Node identity — generates PQC keypair, derives bech32m SEAL address
  - App deployment — deploys blog.seal and market.seal with schemas                                                                                    
  - SQL engine — CREATE TABLE, INSERT, SELECT with WHERE clauses                                                                                     
  - Row-Level Security — alice can update her products, bob can't                                                                                      
  - Cross-app visibility — public vs private table access                                                                                              
  - Block production — produces block #1 with state root hash
                                                                                                                                                       
  ---                                                                                                                                                  
  Interactive REPL                                                                                                                                     
                                                                                                                                                       
  cargo run -p seal-app                                                                                                                              

  Live SQL shell:
  - Type SQL directly (CREATE TABLE, INSERT, SELECT, UPDATE, DELETE)
  - .tables — list tables with row counts                                                                                                              
  - .status — node height + state root   
  - .wallet — PQC + Ed25519 keypair info                                                                                                               
  - .produce — manually produce a block                                                                                                              
  - .block <n> — inspect block at height
