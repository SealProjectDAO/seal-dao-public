forms.seal

PQC-encrypted surveys on Seal DAO

1. Connect to a Seal node

not connected

2. Pick a form

The form's ML-KEM-768 public key is fetched from the forms table. Your answer will be encapsulated against it and only the owner can decrypt.


    


    

      
3. Answer

      
Load a form to see its prompt.

      
      

        
        
      

      

    


    

      
4. Audit (optional)

      
Walks the trace chain from the form's genesis hash to the most
        recent response and confirms it's intact. Auditors do not need
        the encryption key — only the on-chain ciphertexts.

      
      

    

  


  

    This demo uses the WASM SDK at
      ../../sdks/wasm/pkg/. Build it with
      cd sdks/wasm && ./build.sh if the page reports
      a missing module.
